# DMPC2000

Custom (unofficial) OS for the **Akai MPC2000 Classic**, built from reverse-engineered stock v1.72 firmware.
Extended features and workflow improvements. Not affiliated with Akai Professional.

### Note
Still testing and finding bugs, but these features are working on my machine and I am able to persist the changes with saved songs.
New features are going to be added overtime. Will be investigating bitcrushing capabilities/resampling, and other workflow quality of life things in the near future.


> **Compatibility:** Songs saved with modified OS features will not load properly on stock 1.72. Keep that in mind before switching.

## Features

| Version | Date | Notes |
|---------|------|-------|
| **v1.0.2** | 2026-09-13 | Mute groups (32 groups; assign pads via Program menu → Mode: Mute) |
| **v1.0.1** | 2026-09-10 | Pitch clamp increased by ±12 semitones ( down to −36 / up to +36 ) |

## Install

1. Unzip the release.
2. Copy `MPC2000.EXE` and `MPC2000.SYS` to a floppy disk (USB floppy drive works fine).
3. Boot / load the OS on your MPC2000 Classic as you would with stock firmware.
